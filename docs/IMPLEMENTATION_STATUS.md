# T-00~T-03 및 F-REPORT 구현·검증 기록

확인일: 2026-10-02. 현재 범위는 입력 사전 검사, 문서 구조·서식 읽기, 무변경 원본 사본 내보내기와 별도 보고서·논문 작성 초안이다. FR-02·03, AC-01~06 및 AC-16의 무변경 항목을 검증했다. 정식 출시나 G0 전체 통과 기록이 아니다.

## 구현

- T-00: React·TypeScript·Vite, Node 24.19.0/npm 11.9.0, 고정 dependency와 lockfile, 정적 빌드·검증 스크립트.
- T-01: ZIP/XML 라이브러리 비교, 라이선스·지원 매트릭스, 결정적 합성 HWPX 5종과 golden. 실제 한글에서 조판 확인한 문서라는 보장은 없다.
- T-02: 형식 판별, ZIP CRC·경로·암호·압축·크기 검사, UTF-8 XML·외부 참조·활성 자원 제한, private 원본 사본과 해시, 바이트 동일 내보내기. 한컴 패키지 관례와 비실행 XML 메타데이터 호환성은 [HWPX_COMPATIBILITY.md](HWPX_COMPATIBILITY.md)에 기록했다.
- T-03: 선언 순서에 따른 구역·문단·run·표·행·셀, 실제 텍스트, 글꼴·글자/문단 모양·스타일 참조와 단위·출처, 원본 UTF-8 byte sourceSpan, 구조 경로, 미해석·읽기 전용 사유. 자세한 범위는 [DOCUMENT_INSPECTION.md](DOCUMENT_INSPECTION.md)에 있다.
- 화면: 기존 Worker·취소·교체·원본 다운로드 흐름에 문서 구조 보기를 연결했다. 구역 선택, 문단 번호 이동, 표 셀→문단 이동, 서식 상세와 제한된 목록·긴 텍스트 탐색을 제공한다. 문서 교체 때 탐색 상태를 초기화한다.

원본 읽기 모델은 `INSPECT_ONLY`, `editingEnabled=false`다. 원본의 미해석 서식 값을 추정하거나 기본 ID 0으로 대체하지 않는다. 업로드 XML 전체 재생성·편집·재압축은 하지 않는다. Worker protocol 2는 읽기 모델과 별도 작성 초안 요청을 처리하며, 원본 bytes·XML tree·파일명·해시는 결과에 넣지 않는다. 초안 결과에는 독립 검사를 통과한 새 파일 bytes가 포함된다. 원문·파일명·해시의 지속 저장과 외부 전송은 없다.

## 별도 작성 초안 — F-REPORT

사용자의 ‘줄글을 연구대회 보고서 또는 논문으로, 내용 구성도 변경’ 요청에 따라 추가한 기능이다. 기존 T-04의 원본 교정 출시를 열지 않고, 라이선스·digest를 고정한 공개 blank template으로 새 작성 초안을 생성한다. 원본 사본은 계속 바이트 동일하게 내보낸다.

- 2026 수업혁신사례연구대회 **전국 운영계획**을 공식 교육청 게시본에서 확인했다. 본문·본문 제목 휴먼명조12pt, 줄간격160%, 요약서→목차→본문→부록을 적용한다. 전국 서식6의 연구형태·출품교과·학년·학생수 입력을 받고 관리번호는 공란이다. 단위 생략값의 mm/pt 해석과 앱 기본 A4는 공식 명시값과 구분한다.
- 원문 키워드 기반 역할 추천, 전체 문단 검토·검색·역할 수정·40문단 페이지·3000자 원문 창을 제공한다. 역할 안의 원래 순서를 유지하며 연구 사실·수치·인용을 작성하지 않는다. 논문은 기관 서식 미지정 참고 구성이다.
- 입력과 할당을 첫 await 전에 복사하고 ID 및 정확한 원문 텍스트에 결합한다. 원본 XML을 수정하지 않으며, 본문 2000문단·200만 문자 한도를 적용한다. 표·각주·필드·첨자·알 수 없는 구조·모호한 서식 참조는 차단한다.
- 새 ZIP를 독립 재개봉하여 원문 문단 ID/문자/순서, 추가 제목·표지 문자열, 참조·언어군 글꼴·글자크기·간격·용지여백, 캐시 없음과 실제 자원 한도를 확인한다. 새 Preview 텍스트는 출력에 맞게 만들고 공개 template의 이미지·저자/날짜·잘못된 caret 위치를 남기지 않는다.
- 설정·역할 변경은 이전 결과를 비우고, 화면 이동은 검토 상태를 유지한다. 취소/종료는 Worker와 결과 bytes를 폐기하며 늦은 결과도 비운다. 준비 후 오프라인 생성·취소·다시 생성·다운로드에 HTTP 요청과 지속 저장이 없다.
- 원문이 숨겨질 수 있는 비정상 줄 캐시·직접 run 텍스트·XML 공백 외 문자·첨자 호환 분기·중복 참조를 실제 합성 ZIP로 재현하고 차단 회귀를 추가했다.

공식 원문·지원 범위·실제 한글 미실행 한계는 [RESEARCH_DRAFT.md](RESEARCH_DRAFT.md), 공개 blank 출처·라이선스는 [third-party/hwpxlib-draft-template/README.md](third-party/hwpxlib-draft-template/README.md)에 있다. 페이지 수·익명성·연구 근거·표지 외형 및 한글 저장/재개방은 자동 검증으로 대체하지 않는다.

서로 다른 자동 시험은 총 **736개**다. 기존 입력·구조 읽기 601개에 작성 초안 회귀 135개를 추가했다. 중첩 경로에서 같은 시험을 반복한 횟수는 새 시험으로 더하지 않았다. 최종 실행에서 실패·skip은 없다.

합성 golden 5종의 실제 텍스트·선언 순서·표 구조를 비교했고, 모든 모델 노드의 span을 원본 ZIP entry 바이트로 독립 확인했다. BOM·CRLF·한글·emoji·entity·CDATA·제어 탭/줄바꿈, 누락·중복 서식·글꼴, 잘못된 표 주소·병합·중첩, 필드 범위와 미지원 namespace를 검사했다. 세션 getter·Worker 전송 사본·모델을 변경해도 원본과 바이트 동일 출력이 유지된다.

새 읽기 경로에서도 기존 XML 안전 gate를 유지한다. 패키지 누적 요소+텍스트/UTF-8 텍스트 예산, 매우 긴 namespace·local·entry 경로의 모델 증폭, 중복 ID lookup과 공유 서식 값의 처리량·메모리를 제한했다. UI는 긴 font 이름도 일부만 표시하고 원문을 React 텍스트로 렌더링한다.

브라우저에서는 실제 Worker의 문단·서식·표 결과, 구역 선언 순서, 셀→문단 이동, 문서 교체 상태 초기화, 85개 문단의 제한된 DOM과 emoji 텍스트창, 매우 긴 글꼴 이름, 원본 다운로드를 확인했다. 준비 후 오프라인 검사·종료·취소·재검사 동안 HTTP 요청이 없고 브라우저 지속 저장소에 문서 데이터가 없다. 좁은 화면·200% 확대의 자동 확인은 모바일 실기기 검수 완료가 아니다.

`npm run test:deployed`는 공개 사이트에서 정확한 commit, Worker·본문·글자 크기·spine 순서·표 셀, 원본 다운로드와 오프라인 재시작을 확인하도록 확장했다. 작성 초안도 공개 사이트에서 오프라인 생성·다운로드·원문 재개봉·설정 변경 결과 무효화를 시험한다. 공개 URL 결과는 해당 main Actions 실행의 smoke job으로 확인한다. loopback HTTP preview의 성공을 공개 사이트 성공으로 취급하지 않는다.

## 남은 제한

- 사용자 파일은 받지 않아 그 파일의 성공은 미확인이다. 실제 HWPX의 모든 변형을 지원하지 않는다. HWP/PDF 변환·암호화·ZIP64는 지원하지 않는다.
- 서식 기준 설정·규칙 평가·승인·최소 교정·공유 서식 복제·전체 되돌리기·재적용은 미구현이다. 원본 출력은 바꾸지 않은 사본이며, 새 작성 초안은 F-REPORT의 별도 기능이다.
- AC-32·33 실제 Windows·한컴 한글 개봉·조판·캐시 검수는 **미실행**이다. 확인자·실제 빌드 기록이 없고 원본 편집 범위는 열지 않았다. 새 문서는 검증 전 작성 초안으로 표시한다.
- 실제 모바일 기기 AC-30과 새 환경 snapshot 복원은 미검증이다. 개발 환경의 기존 pinned 도구·실행 스크립트는 사용 가능하며 추가 설정 변경은 필요하지 않았다.
