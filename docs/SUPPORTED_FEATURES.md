# 지원 매트릭스 — 검사·작성 초안

현재 범위는 안전 입력, 문단·표·서식 참조 읽기, 무변경 원본 반환과 별도 줄글 작성 초안이다. 편집 속성, 한글 출력 호환성, 실제 조판은 아직 지원으로 선언하지 않는다. 다섯 공개 fixture는 한컴이 생성·검증한 파일이 아닌 직접 조립한 합성 패키지다.

| 영역 | 시험 범위 | 현재 지원 등급 | fixture·AC | 한글 빌드·수동 결과 |
| --- | --- | --- | --- | --- |
| 패키지 식별 | 첫 STORED `mimetype=application/hwp+zip`, OCF container→OPF | 안전 입력 판별 대상 | 전체, AC-01~03 | 미실행 |
| 한컴 패키지 관례 | OPF 끝 `/` 두 정확 URI, ZIP 루트 경로, spine header, 보조 preview/RDF rootfile | `INSPECT_ONLY`; 모호한 경로·선언은 거부 | 메모리 합성 호환성 회귀 | 미실행 |
| 비실행 XML 메타데이터 | XSI schema hint, OPF meta.content, RDF 식별자와 hp:switch/case의 required-namespace | 정확한 문맥의 문자열만 읽고 주소 조회·실행 없음 | XML 단위·보안·브라우저 회귀 | 미실행 |
| 버전 선언 | `major=5 minor=1 micro=0 buildNumber=0`, `xmlVersion=1.5` | 합성 입력 탐색 후보, 실제 버전 지원 미확정 | 전체 | 미실행 |
| 일반 순수 텍스트 문단 | 한글·특수문자·연속 공백·탭·줄바꿈 | `INSPECT_ONLY` | 01, AC-05 | 미실행 |
| 다른 namespace prefix | section/paragraph/head/core/OPF URI 동일 | `INSPECT_ONLY` | 02, AC-05 | 미실행 |
| 여러 구역 | OPF spine 2→0→1 | `INSPECT_ONLY` | 03, AC-04 | 미실행 |
| 단순 표 | 텍스트 셀 2×2 | `INSPECT_ONLY`, 실제 행·셀 구조 읽기 | 04, AC-06 | 미실행 |
| 병합·중첩 표 | 병합 셀·중첩 표 경계 | `INSPECT_ONLY`, 교정 차단 | 05, AC-06 | 미실행 |
| 글꼴 참조 | 기존 언어군 font ID 0, 합성 head | 실제 언어군·정의 참조 읽기; 누락·중복은 unknown, 변경 비활성 | 전체, AC-14 후속 | 미실행 |
| 글자 크기 | 1100/1200 합성 모양 | HWPUNIT 원값과 pt 환산 표시; 변경 비활성 | 전체, AC-10·14 후속 | 미실행 |
| 원본 줄 배치 캐시·Preview | 검증한 편집 정책 없음 | 원본 편집 비활성 | AC-33 | 미실행 |
| 무변경 내보내기 | 입력 전체 ZIP 바이트 동일 반환 | T-02 자동 시험 대상 | 전체, AC-16 | 원본 반환은 조판 검증을 주장하지 않음 |

이 목록의 형식 버전은 fixture에 넣은 선언이며 해당 버전 전체를 지원한다는 뜻이 아니다. 최소 합성 header에는 완전한 스타일·레이아웃 구조가 없다. 업로드 문서 전체 재생성, 자동 font 대체, merged/nested table 교정, 실제 페이지 배치 판단을 제공하지 않는다. 입력이 받아들여졌다는 사실과 한글에서 정상 개봉된다는 사실을 구분한다.

T-03은 원본 UTF-8 byte span, 선언 순서, 실제 문단·run·표·참조와 읽기 전용 사유를 제공한다. 병합·중첩 표, 필드·머리말·꼬리말·주석·개체, 미확인 서식은 교정 대상으로 취급하지 않는다. 자세한 지원 범위와 합성 시험 근거는 [DOCUMENT_INSPECTION.md](DOCUMENT_INSPECTION.md)에 있다. T-04 편집 활성화에는 지정 Windows·한글 실제 빌드, 확인자·확인일·fixture·속성별 AC-32/33 결과와 원문·비대상 보존 시험이 필요하다. 결과를 기록하기 전까지 `EDITABLE` 지원 범위는 비어 있다.

## 별도 작성 초안 — F-REPORT

사용자가 요청한 내용 재구성 기능은 업로드 원본을 교정하는 T-04와 별도의 기능이다. 라이선스와 digest를 고정한 공개 blank template으로 **새 문서**를 만들고, 승인한 역할에 따라 원문 텍스트를 옮긴다. 보고서·계획서·설명서는 모든 원문 문단을 정확히 한 번 옮기며 요약서의 명시적으로 확인한 선택은 아래 별도 정책을 적용한다. 업로드 XML·표·자원을 재생성하거나 수정하지 않는다. 원본 읽기 모델의 `editingEnabled=false`와 바이트 동일 내보내기는 유지한다.

| 영역 | 작성 초안 지원 | 제한 |
| --- | --- | --- |
| 자동 구성 | 원문 키워드에 따른 추천, 문단별 역할 수정, 역할 내 원래 순서 유지 | 연구 내용·성과·인용문 작성 없음 |
| 수업혁신 양식 | 2026 전국 운영계획 본문 휴먼명조 12pt·160%, 요약서·목차·본문·부록 | 본문 장 제목은 작성 제안, 최종 표지·페이지·제출 공문 확인 필요 |
| 논문 | 초록·서론·방법·절차·결과·논의·참고문헌·부록 참고 구성 | 제출 기관 공식 양식 아님 |
| 순수 본문 | Unicode·연속 공백·탭·줄바꿈, 여러 구역 텍스트 | 2,000문단·200만 문자 |
| 구조 차단 | 표·그림·수식·각주·필드·미지원 컨트롤·모호한 참조·첨자 | 지원하지 않는 내용을 버리고 성공 처리하지 않음 |
| 레이아웃 metadata | 엄격히 확인한 secPr/colPr·비텍스트 줄 캐시는 원문에서 읽음 | 새 초안은 새 용지·서식과 캐시 없는 문단, 원본 캐시 편집 정책 검증 아님 |
| 출력 검증 | 실제 새 ZIP/XML 재개봉, 참조·font·크기·간격·용지·문자·순서 확인 | Windows 한컴 한글 개봉·조판·저장·재개방 **NOT_RUN** |
| 결과 상태 | 옵션/역할 변경 무효화, 취소·늦은 결과 폐기, 화면 이동 시 검토 상태 유지 | 새로고침·종료 시 삭제, 지속 저장 없음 |

수업혁신사례연구대회 출처·단위 해석·공식 표지·수동 검증 제한은 [RESEARCH_DRAFT.md](RESEARCH_DRAFT.md)에 기록한다. 자동 교정 정식 출시나 AC-32·33 통과를 선언하지 않는다.

## 대회 선택·작성 보조 — F-COMPETITIONS

사용자가 전체 제안의 구현을 요청해 확장한 별도 작성 초안 범위다. 원래 T-04 원본 patch 출시 게이트를 통과하거나 원본 편집을 활성화했다는 의미가 아니다. 공식 자료 확인 상태·작성 정책·실제 한글 검수 상태를 구분하며, 최신 자동 시험 결과는 [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md)에 기록한다.

| 영역 | 제공 범위 | 제한 |
| --- | --- | --- |
| 대회 목록 | 2026 자료 대회군10개, 2025 교원발명 참고, 사용자 기준·논문: 총13개 유형/29개 작성 기준 | 전체 전국 연구대회 목록이나 참가 가능성·입상 인증 아님 |
| 이름·필터 | 정식명·옛 이름 검색, 학교급·연도·분과·작성 단계·문서 종류 | 옛 이름 별도 중복 등록 없음, 없는 연도 규정 추정 없음 |
| 기준·출처 | 전국 원문/지역 계획의 전국 안내/전년도 자료, 버전·확인일·조항과 공식 명시/해석/앱 기본값 구분 | 지역 수치를 전국 공통으로 확대하지 않음, 후속 공문 직접 확인 |
| 문서별 서식 | 대회별 보고서·요약서·계획서·지원서·설명서, 서식만 적용·참고·안내 정책 | 공통 12pt·160% 일괄 적용 없음, 실제 쪽수·인쇄 결과 미확정 |
| 인성교육 | 최초 작성·시도 제출 전 교원/기관 참고 초안, 앱 기본값 명시 | 전국 단독 전체 서식 미확인; 전국 단계 생성·변경 잠금 |
| EBS 설명서 | 제출 전 기작성 문장의 서식만 적용, 문단 순서 그대로 | 구성 제목·보충 문단·주제·구성안·스크립트 생성 없음; 전국 단계 잠금 |
| 부족한 내용 질문 | 실제 연구 대상·기간·절차·관찰·근거를 확인할 질문과 교사 직접 입력 | 새 연구 사실·성과·인용을 자동 작성하지 않음, 빈 항목은 증빙 아님 |
| 교사 보충 문단 | 직접 입력한 내용을 선택한 항목에 추가하고 원문/추가 수 구분 | 서식만 적용 정책에는 추가 불가, 원문으로 혼동·덮어쓰기 없음 |
| 요약서 문단 선택 | 제외 내용을 확인한 사용자 선택 ID의 문장을 그대로 정확히 한 번 출력, 포함/제외 수 표시 | 제외 문단은 요약서에 들어가지 않음; 원본 bytes 동일 보존, 자동 새 요약·임의 글자 축소 없음 |
| 준비 목록·식별정보 | 영상·실물·SW·추천·발표·동의서, 기명/익명 위치별 확인 항목 | 체크로 연구 진위·자료 존재·익명성·출품 완료를 인증하지 않음 |
| 사용자 서식 | 수동 글꼴·크기·간격·여백·항목 제목의 개인 참고 기준 | 공식 기준 아님, 실제 기관 검토 필요 |
| 교원발명2025 | 전년도 요강의 참고 보고서·요약서 초안 | 2026 운영 미확인, 최신 공식 기준으로 인증하지 않음 |
| 변경·취소 | 기준/역할/입력/선택 변경 시 이전 출력 무효화, 취소·늦은 응답 폐기 | 다른 문서·기준의 검토 상태 자동 승계 없음 |
| 로컬 처리 | 브라우저 메모리, 준비 후 오프라인 검사·생성·다운로드 | 외부 AI·서버·DB·브라우저 지속 저장 없음 |

현재 양식은 **텍스트 중심**이다. 표·사진·수식·개체를 포함한 공식 표지의 정확한 외형·복잡한 양식 채움은 미검증이다. 입력의 표·사진을 조용히 빼고 완료하지 않는다. 실제 한글의 쪽수·글꼴 설치·줄 배치·표지·익명성·HWP/PDF 저장 결과는 **NOT_RUN**이다.

교육자료전은 실제 교육자료, EBS는 본편·메이킹 영상, 디지털 SW·AI는 실행물·소스가 필요한 대회다. HWPX 설명서 한 개로 이 제작물을 준비했다고 표시하지 않는다. 한국교총 두 대회의 공식 형식 `hwp 또는 PDF`, EBS 설명서 `PDF`를 HWPX 제출 승인으로 바꾸지 않는다. EBS 생성형 AI 제한은 [대회 목록](COMPETITION_CATALOG.md)에 원문 범위대로 기록하며 모든 비생성형 서식 자동화 금지로 확대하지 않는다.
