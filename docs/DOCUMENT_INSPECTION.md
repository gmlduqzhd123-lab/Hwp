# T-03 문서 구조·서식 읽기

범위: FR-03, AC-04~06. 모든 입력과 영역은 `INSPECT_ONLY`이며 `editingEnabled=false`다. 실제 한글 조판 검수와 자동 교정은 제공하지 않는다.

## 읽는 정보

- OPF spine이 선언한 구역 순서와 정확한 namespace URI를 따른다. 파일명 정렬이나 prefix 문자열로 구조를 결정하지 않는다.
- 문단·run의 실제 텍스트, 연속 공백, XML에 기록된 탭·줄바꿈, CDATA와 디코딩된 XML entity를 읽는다. 개체를 담은 문단에 표 셀 문단의 텍스트를 중복해서 합치지 않는다.
- 표·행·셀의 실제 구조, 주소와 span을 읽는다. 병합·중첩·잘못된 주소는 사유와 함께 표시하며 선언 크기로 큰 가상 grid를 할당하지 않는다.
- 글자 모양·문단 모양·스타일·언어군 글꼴 정의와 직접 참조를 연결한다. 누락·중복·잘못된 참조와 값은 `null`과 사유로 표시한다. ID 0이나 스타일 기본값으로 대체하지 않는다. `nextStyleIDRef`는 상속이 아니다.
- 글자 크기와 HWPUNIT 길이는 원값과 `/100` pt 값을 함께 보관한다. PERCENT 줄간격은 값 자체를 %로 읽고, CHAR 단위는 pt로 임의 환산하지 않는다. `hp:switch`의 문단 속성 branch는 값을 섞지 않고 확인 불가 사유를 표시한다.

모든 구조 노드는 세션 안에서 결정적인 node ID, 구조 경로, 원래 XML ID(있을 때), ZIP entry 경로와 원본 UTF-8 byte span을 가진다. span은 시작 포함·끝 제외이며 BOM, CRLF, 한글·emoji에 따른 바이트 위치 차이를 반영한다. 디코딩한 텍스트는 XML 1.0의 줄바꿈 정규화 결과다. 원본 bytes는 별도로 보존하므로 텍스트 디코딩이 다운로드 파일을 바꾸지 않는다.

## 지원 경계와 화면

일반 문단과 단순 표에서도 참조가 미확인일 수 있다. 필드, 머리말·꼬리말, 주석, 개체, 위첨자·아래첨자, 알 수 없는 namespace나 제어 요소, 병합·중첩 표는 읽기 전용 사유를 가진다. 내부 `correctionCandidate`는 추후 검증할 수 있는 구조 후보이며 편집 허가가 아니다.

화면의 ‘문서 구조 보기’에서 구역, 문단·표 목록, run 서식과 셀 위치를 탐색한다. 문단·run·셀 목록과 긴 텍스트를 나누어 표시해 문서 크기에 비례한 DOM 폭증을 제한한다. 글꼴 이름은 정보로만 표시하며 원문을 HTML로 실행하거나 문서 자원을 불러오지 않는다. 이 화면은 한글의 페이지 배치·화면 미리보기를 재현하지 않는다.

## 원본 보존과 제한

`inspectHwpx`는 기존 ZIP·XML 보안 검사, 실제 해제 크기·CRC, 패키지 선언 검증 이후 읽기 모델을 만든다. XML reading index의 요소+텍스트 노드와 텍스트 길이도 패키지 전체에서 제한한다. 구조 경로는 512자 이내로 제한하고, 반복되는 모델 ID·위치 정보의 메모리 증가를 막기 위해 읽기 대상 XML entry 경로는 256자까지 허용한다. 더 긴 원본 경로를 잘라서 위치를 바꾸지 않고 자원 제한으로 중단한다. 바이너리 개체는 검증하면서 흘려보내고 읽기 모델에 넣지 않는다.

`createInspectionSession`은 원본을 첫 비동기 호출 전에 복사하고 모델 getter를 복사한다. Worker protocol 2는 같은 탭의 UI로 plain 모델만 보낸다. 원본 bytes·원본 XML·cyclic index·파일명·해시는 결과 모델에 없다. 화면 문서 데이터는 메모리에만 있고 새로고침·종료 후 복원하지 않는다. 원본 다운로드는 재압축·재직렬화 없이 입력 바이트와 동일하다.

## 검증과 남은 단계

합성 golden 5종으로 선언 순서, 다른 prefix, Unicode 텍스트, 단순 표 및 병합·중첩 표를 비교한다. 추가 회귀는 누락·중복 참조, 서식 단위, 원본 byte span, 모델 복사와 원본 다운로드, 보안 제한, 실제 Worker와 브라우저의 구조 탐색을 확인한다. 실행 명령과 최종 결과는 [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md)에 기록한다.

AC-32·33의 실제 Windows·한컴 한글 개봉·조판·캐시 검수는 **미실행**이다. T-04에서 승인 속성 하나의 원본 기반 patch·공유 모양 복제와 실제 한글 검증을 준비해야 한다. 전체 제품 또는 한글 편집 호환성 완료를 주장하지 않는다.
