# 대회 목록과 작성 기준 — F-COMPETITIONS

확인일: **2026-10-02**. 사용자가 요청한 대회 선택·작성 보조 확장이다. 대회 존재와 공식 자료 확인, 줄글 HWPX 초안 생성, 실제 한글·최종 제출 검수는 별개의 상태다. 이 문서는 전국 교원 연구대회의 완전한 목록이나 참가 자격 인증서가 아니다.

## 목록과 지원 정책

‘대회별 작성 기준 찾아보기’는 파일을 올리기 전에도 대회 이름·옛 이름, 학교급·자료 연도로 공식 출처와 준비물을 비교한다. 작성 화면에서는 ‘학교급 선택’ → ‘대회 검색/대회 선택’ → ‘기준 연도’ → ‘문서·분과 선택’ → ‘작성 단계’를 정한다. 현재 코드 목록은 **대회·참고 유형13개, 작성 기준29개**다. 각 작성 기준에는 공식 출처의 연도·범위·확인 위치, 버전, 제출물과 확인 항목을 연결한다. 기준을 바꾸면 이전 생성 결과를 무효화하고 문단 배치를 다시 검토한다. 자료가 없는 연도에 전년도 기준을 당해연도 공식 기준으로 복제하지 않는다.

| 정책 | 제공 범위 |
| --- | --- |
| 작성 초안 | 교사가 검토한 원문을 항목별로 배치하고 선택한 기준의 서식을 적용한 새 HWPX |
| 서식만 적용 | 원문 문장·문단 순서를 유지하고 서식만 적용; 구성 제목·교사 보충 문단 추가 없음 |
| 참고 기준 | 전국 전체 서식 미확인/전년도 기준, 기관 미지정 논문 또는 사용자 개인 기준의 초안; 최신 공식 양식으로 인증하지 않음 |
| 안내 전용 | 출처·참가 조건·제출물·준비 목록 확인; 해당 기준의 새 초안 생성 없음 |

현재 생성 양식은 **줄글 중심**이다. 표·사진·영상·개발물·실물 자료를 만들거나 옮기지 않는다. 공식 표지의 정확한 외형, 복잡한 공식 양식의 셀 채움, Windows 한컴 한글 개봉·조판·저장·재개방은 **NOT_RUN**이다. HWPX는 준비용 초안이며 최종 제출 확장자 승인을 뜻하지 않는다.

## 구현된 작성 기준 ID와 단계

구현 위치는 `src/domain/competitions.ts`다. 2026 기준 버전은 `2026-10-02-v1`, 교원발명2025 참고 기준은 `2025-checked-2026-10-02-v1`이다. 같은 대회 안의 분과·문서 종류도 각각 다른 작성 기준으로 검사한다. 아래 단계는 앱의 생성 허용 범위이며 참가 승인이나 접수 마감 판정이 아니다.

기명·익명도 문서별로 다르다. 수업혁신은 표지·본문·부록의 식별정보를 제외한다. 현장교육·교육자료전은 겉표지 기명과 속표지·본문 익명을 구분한다. EBS 게시용만 소속·직위·성명·공동역할을 포함하고 심사용은 인적사항·공동역할분담을 기재하지 않는다. 앱은 이 차이를 확인 항목으로 안내하며 모든 인명·사진·메타정보를 찾거나 익명본을 인증하지 않는다.

## 전국 단계 잠금과 EBS 생성형 AI 조항

인성교육 전국 안내와 EBS 전국 운영계획은 시도에 낸 원고·작품의 수정·변경을 금지한다. 전국 진출 후에는 새 배치·서식 초안을 생성하지 않고 원본 검사·바이트 동일 사본과 준비 항목 확인을 제공한다. 전국 단독 인성 서식이 미확인이라는 사유와 제출 후 변경 금지라는 사유를 구분한다.

EBS 2026 운영계획 `Ⅲ.5 심사 제외 사항 / 생성형 AI 활용 시 유의 사항`은 생성형 AI를 **주제·소재 선정, 구성안·스크립트 작성**에 활용하면 심사 제외라고 명시한다. 전체 AI 제작 또는 부분 AI 제작량이 전체의 **1/5 이상**인 경우도 제외하며, 제작·편집 프로그램의 AI 기능에 동일 적용하고 활용내용을 작품 화면·작품설명서·저작권 보증서에 기재하도록 한다. 이 조항을 모든 비생성형 행정 편집·단순 서식 자동화 금지로 확대하지 않는다. 이 앱은 AI API를 사용하지 않으며 EBS용 주제·소재·구성안·스크립트를 새로 작성하지 않는다.

## 원문·질문·요약·준비 목록

보고서·계획서·설명서 초안은 승인한 모든 원문 문단을 정확히 한 번 옮기며 역할 내 원래 순서를 유지한다. 질문에 대한 답은 **교사가 직접 입력하고 포함을 확인한 실제 연구 내용**만 별도 보충 문단으로 추가하고 원문 문단 수와 추가 문단 수를 구분한다. 입력만 한 내용은 넣지 않는다. 기준·단계·학교급 변경 또는 문장 수정 후에는 포함 여부를 다시 확인한다. 질문이나 빈 제목을 보여 주는 것은 근거·실천·성과가 확보되었다는 판정이 아니다.

요약서에서는 교사가 원문 문단을 골라 제외 내용을 확인한 경우에만 그 선택을 적용한다. 선택한 문단은 원래 문장을 그대로 정확히 한 번 출력하고 포함·제외 수를 표시한다. 선택하지 않은 문단은 **요약서 출력에서 의도적으로 제외**되며, 업로드 원본과 원본 사본은 바이트 동일하게 유지한다. 자동 새 요약문·성과·인용을 만들거나 페이지 상한에 맞추려고 글자를 임의 축소하지 않는다.

‘준비물과 제출 전 확인’은 사용자의 확인을 돕는 목록이다. 체크는 파일 내용을 바꾸지 않으며 추천·영상·실물·증빙·연구 진위·익명성·제출 완료를 인증하지 않는다. 선택·입력·체크 상태와 문서는 브라우저 메모리에서 처리하며 외부 AI·서버·DB·브라우저 지속 저장소를 사용하지 않는다. 로컬 검사 준비 완료 후의 검사·생성·다운로드는 오프라인 동작 범위다.
